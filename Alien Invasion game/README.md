# Alien Invasion Game 🎮

A 2D arcade-style game inspired by the classic "Space Invaders," built using **Python** and **Pygame** library. The player controls a spaceship to shoot down waves of aliens and score points while avoiding collisions. 

---

## Features 🚀
- **Interactive Gameplay**: Navigate the ship, shoot bullets, and eliminate alien fleets.
- **Dynamic Difficulty**: Speed increases as levels progress.
- **Score Tracking**: Displays the player's current score, high score, and level.
- **Play Button**: Start a new game or restart after losing.
- **User-Friendly**: Easy to understand and fun to play!
