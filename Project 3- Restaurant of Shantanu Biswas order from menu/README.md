Restaurant Ordering System
This Python program simulates a simple restaurant ordering system, where users can view a menu, place an order, and calculate the total cost.

Features:
Displays a dynamic menu of items with prices.
Allows users to order up to two items from the menu.
Validates user input to ensure items are available.
Calculates and displays the total cost of the order.
Handles case-insensitive inputs for menu items.
Provides clear feedback for unavailable items or invalid inputs.
How It Works:
The program displays a menu of items with prices.
Users can input the name of an item they wish to order.
If the item is in the menu:
It is added to the order, and the price is included in the total.
Users can decide whether to order a second item.
The total order cost is displayed at the end.
